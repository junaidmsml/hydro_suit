🌧 Precipitation Analyzer

Analyze • Visualize • Understand

by Junaid Ali

A scientific web application for analyzing rainfall data from CSV or Excel files. Upload your dataset and get instant statistics, time-series charts, extreme event detection, anomaly analysis, and downloadable PDF reports — all in your browser.

Key Features

Automatic column detection
Data quality check
Basic statistics
Daily / monthly / annual charts
Cumulative mass curve
Top 10 extreme events
Anomaly analysis
PDF report generation
